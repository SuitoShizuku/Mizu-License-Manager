# Mizu License Manager

Windows 11向けの日本語ライセンス管理アプリです。

## 起動

`Mizu-License-Manager_v1.0.0.zip`（以後バージョンを更新）を展開し、`Mizu-License-Manager.exe` をダブルクリックしてください。配布用フォルダには.NETランタイムを同梱しています。Windows 11 x64向けです。フォルダ全体をコピーして使えます。

起動時から通知領域に常駐します。×やAlt+F4はウィンドウを隠すだけで、未保存の入力も保持します。通知領域の水滴アイコンをクリック、または右クリック→「ウィンドウを表示」で戻れます。完全に終了するには右クリック→「終了」を選びます。未保存の変更があれば破棄の確認を表示し、保存・送信処理中は終了を待ってもらう案内を表示します。Windows起動時の自動起動を登録する機能ではありません。

## 使い方

「設定」のテーマで「ライト」「ダーク」「OSに依存」を選べます。選択時にプレビューし、設定保存で確定します。OSに依存の場合はWindowsのアプリモードに追従します。設定を保存せず閉じると元に戻ります。

「タグ」にアプリ名（After Effects、Photoshopなど）や分類を入力し、「追加」またはEnterでチップとして複数登録できます。登録済みのタグは候補になり、×で削除できます。左側のタグタブを選ぶと、そのタグのライセンスに絞り込めます。タブは1つずつ選択し、文字検索・状態フィルターとも組み合わせられます。「すべて」でタグの絞り込みを解除します。タグはJSON・暗号化バックアップの両方に含まれ、以前の対応アプリのデータもそのまま引き継がれます。

一覧は項目単位ではなくピクセル単位でスクロールします。ホイール操作は短い補間アニメーションで滑らかに移動し、スクロールバーのドラッグやキーボード操作は直接追従します。Windowsのアニメーション無効設定にも従います。

一覧と入力欄の幅は36:64です。一時的有効の有効期限は、状態ラジオボタンの右側に表示されます。

1. 「設定」で「新規メールアドレス」「新規デバイス」を押すと、入力行が1つ増えます。各項目を編集して設定を保存します。登録済みの名前を変えると、それを参照しているライセンスにも反映されます。順番が変わっても対応がずれないよう、内部では固定IDで参照します。
2. 「＋ ライセンスを追加」で詳細を入力し、「変更を保存」を押します。
3. ライセンスキーは初期状態では伏せ字です。「表示」を押すと確認でき、ボタンが「非表示」に変わります。再度押すかウィンドウが非アクティブになると再び隠れます。
4. パスの入力欄をクリックすると、ファイル／フォルダの選択メニューが開きます。
5. 開発元は入力済みの値が次回から候補になります。デバイスは設定に登録したリストから選択後に「追加」を押します。複数登録でき、×で選択を外せます。新しいデバイスは設定画面で登録してください。
6. 各項目の「コピー」で内容をクリップボードにコピーできます。キーは伏せ字のままでもコピーできます。

7. 主ライセンスキーの見出し横の「＋」で、名前と追加キーの行を追加できます。値は初期状態で隠れ、各行の表示／非表示・コピー・×で操作します。名前は右クリックでコピーできます。追加キーも通常の保存・暗号化バックアップに含まれます。
8. 一覧の右上の☆を押すとお気に入りになり、★として上位に表示されます。再度押すと解除します。お気に入りはその場で保存され、設定済みの場合はDiscordバックアップも送信します。
9. タグのチップ、一覧内のタグ、絞り込みタブを右クリックすると、色を選べます。同じタグは共通の色を使い、色はその場で保存されます。「標準に戻す」でテーマ標準色に戻せます。
10. タグ・開発元・対象デバイスは入力欄にフォーカスすると候補を自動表示します。タグと開発元は手入力・補完も使えます。デバイスは設定リストからの選択専用です。未追加の入力や選択がある間は「＋ 追加」が青く強調されます。追加した後に「変更を保存」を押してください。
11. ファイル・フォルダパスの「開く」は、登録したアプリ／ファイルを起動するかフォルダを開きます。URLの「開く」は既定のブラウザーで開きます（http/https）。見出し横の「＋」でURL入力行を追加でき、各行に開く・コピー・削除があります。追加URLは保存・バックアップ・復元に含まれます。

名称・開発元・メール・メモ・デバイスを検索できます。状態は「現在有効」「現在無効」「一時的有効」のラジオボタンで選択し、一覧も各状態で絞り込めます。有効期限は「一時的有効」の場合のみ表示・保存されます（期限による状態の自動変更はありません）。旧データの有効／無効は引き継がれます。新規追加時はメールも未選択になります。変更は保存ボタンで確定します。JSON書き出しは保存済みの内容が対象です。

## Discordバックアップ

設定画面でDiscordから取得した `https://discord.com/api/webhooks/...` 形式のURLを保存します。以後、ライセンス保存・削除・復元・設定保存のたびに、全ライセンスとメール／デバイス候補を1ファイルとして送信します。URLを空欄にすると停止します。

「暗号化」トグルがOFFなら平文の `.json`、ONならパスフレーズで内容を暗号化した `.mlicense` を送信します。ONにする際はパスフレーズと確認欄を入力してください。パスフレーズはPC内のDPAPI暗号化データに保存し、自動送信に使用します。Webhook URLはバックアップに含み、読み込み時に復元します。パスフレーズ自体は含めません。手動の「JSON書き出し」はトグルに関係なく平文です。

平文JSONはライセンスキーも含み、送信先チャンネルの閲覧者が内容を読めます。各保存で新しい添付ファイルが投稿され、過去の投稿は残ります。

`.mlicense` はAES-256-GCM（認証タグ16バイト）で暗号化します。PBKDF2-HMAC-SHA256・600,000回でパスフレーズから鍵を導出し、毎回ランダムな16バイトのソルトと12バイトのnonceを使用します。バージョン付きヘッダー・ソルト・nonce・認証タグ・暗号文を含むバイナリ形式です。誤ったパスフレーズや改ざんされた暗号文では復号できません。

「バックアップ読込」で `.mlicense` を選ぶと、毎回パスフレーズの入力を求めます。パスフレーズを忘れると復元できません。設定で変更した場合でも、過去のファイルには暗号化時のパスフレーズが必要です。

PC保存が先に完了し、送信結果を画面下部に表示します。通信失敗・レート制限・添付サイズ制限などの際もPC保存は失われません。「バックアップ再送」で現在の保存済みデータを再送できます。自動再試行や終了後の送信予約はありません。

## ローカル保存と復旧

保存先は `%LOCALAPPDATA%\MizuLicenseManager\vault.dat` です。Windows DPAPIで、実行中のWindowsユーザー用に全データを暗号化します。同じユーザー権限のプログラムからのアクセスを防ぐものではありません。二重起動は防止しています。

保存は一時ファイルから置換し、直前のデータは `vault.dat.bak` に残します。破損した保存データを検出した場合は上書きせず終了します。復旧する場合は、アプリを終了して現在のファイルを別の場所に保管し、`vault.dat.bak` を `vault.dat` にコピーしてください。

別PCへの移行は「JSON書き出し」→「バックアップ読込」、またはDiscordに保存された `.mlicense` の読み込みを使います。復元はライセンスと候補リストを全件置換し、Webhook URLはバックアップ内の値で復元します。URLが空の旧バックアップでは現在値を保持します。暗号化設定・送信用パスフレーズは現在値を保持します。暗号化済みdatファイルの別ユーザー／別PCへの移動は想定していません。クリップボードと書き出したJSONには平文の値が入ります。

## 開発

.NET 8以上のSDKとWindowsが必要です。追加NuGetパッケージはありません。

```powershell
dotnet build -c Release
dotnet run --project tests/Mizu.Tests.csproj -c Release
dotnet run --project tests/UI/Mizu.UiTests.csproj -c Release
.\Publish-Release.ps1
```

配布生成は `Publish-Release.ps1` を使用します。初回はv1.0.0、次回からは `release-version.json` の前回リリース番号のpatchを1つ増やし、EXEのバージョンにも反映します。出力は `dist/Mizu-License-Manager_vX.Y.Z/` と同名のZIPです。成功時のみ番号を更新し、既存の成果物は上書きしません。通常のビルドやテストでは番号は変わりません。

テストは一時ディレクトリと偽HTTPハンドラーを使用します。暗号化保存、置換バックアップ、全件JSON復元、Webhook URLの保存・復元、不正URLとJSONの拒否、送信失敗時のローカル保存を検証します。実際のDiscordへの送信にはユーザーのWebhook設定が必要です。

API仕様: [Discord Webhook](https://docs.discord.com/developers/resources/webhook)、[Windowsフォルダ選択ダイアログ](https://learn.microsoft.com/en-us/dotnet/api/microsoft.win32.openfolderdialog)。
