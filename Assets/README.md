# Mizu icon

Created using the built-in image_gen tool. The original PNG is `Mizu.png`; `Build-Icon.ps1` packages it as a multi-resolution Windows icon in `Mizu.ico` (16–256px). Used in the EXE, main window and system tray.

Prompt:

Use case: logo-brand. Asset type: Windows 11 application icon for Mizu License Manager, a personal software license vault. Create one polished square icon, centered, with genuine transparent background outside the icon silhouette. Subject: a bold blue water droplet with a simple white keyhole inset, combining Mizu (water) and safe license storage. Rich cobalt and cyan with restrained soft depth, crisp large simple silhouette recognizable at 16px, modern Windows desktop icon aesthetic. No text, no letters, no tiny detail, no scenery, no mockup, no border frame, no watermark. Droplet fills roughly 85 percent of square canvas, generous consistent transparent margins, high contrast on light and dark backgrounds.
